# Skill / Job Progression

## Job Classes
- Warrior: Heavy melee DPS (combo skills)
- Knight: Defensive tank (sword combo)
- Magician: Elemental spells (fire, ice, lightning)
- Cleric: Healer (holy magic)
- Hunter: Ranged DPS (bow, gun)
- Jester: Stealth (knife combo)
- Craftsman: Crafting/refining

## Level Requirements
- Base class: Level 1
- First job change: Level 10
- Second job change: Level 30+
